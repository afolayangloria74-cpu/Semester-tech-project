# Semester-tech-project
For cybersecurity
I didn't just wake up and like computers. I started by asking - why do people still fall for scam emails when everybody knows about scammers?

That one question carried me into Cybersecurity Fundamentals. I wanted to understand how people think, how systems get broken, and how we can stay safe online. I learnt about CIA Triad, phishing, social engineering, and password security.

Along the line I realized something: you can't really protect what you don't understand. How does data even move from one place to another?

That's why I moved into Networking. Now I'm learning hands-on - IP addressing, OSI model, routing and switching, and how devices communicate.

Hands-On Practice
Project: Home Network Setup - Cisco Packet Tracer
I designed and connected a simple home network using a router, switch, and 3 end devices. I assigned IP addresses, used the right cables, and tested connectivity with ping. This lab helped me understand how our home networks actually work beyond theory.

Tools: Cisco Packet Tracer, Python (Basics)

I have had the opportunity to learn all of this through Semester Technologies, which has given me a solid foundation and hands-on exposure.

What I'm focused on now:
- Building a strong foundation in Networking
- Practicing more real-life labs
- Growing into more advanced security concepts

I'm open to learning more and joining communities where I can grow and contribute.
